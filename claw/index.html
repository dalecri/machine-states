The slider drives the large machine. Each tile is an independent instance. Use “Jam it” during a run, then “Release the grip” to resume from the frozen count.

mountMachine(el, { machine: 'claw', items, batchLabel })
Returns play(), setProgress(0..1), setState(name), setCopy(copy), destroy(). States: idle, feeding, scanning, clearing, done, error. Working phases also accept 'working, scanning' or { name: 'working', phase: 'scanning' }. Listen for machine:change and machine:action.
